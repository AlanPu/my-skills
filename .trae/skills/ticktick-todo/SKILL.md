# 滴答清单待办事项创建器

## 功能
- 打开电脑上的滴答清单软件
- 在滴答清单中创建新的待办事项
- 支持设置任务标题、描述、截止时间等属性
- 支持从日历截图中识别预约的日期和时间
- 自动将任务开始时间提前10分钟，任务内容显示原始时间

## 使用方法

### 方法 1：官方 URL Scheme（推荐）
使用 TickTick 官方推荐的 URL Scheme 方法，无需权限，直接创建任务：

```bash
# 运行此脚本创建任务
bash .trae/skills/ticktick-todo/create_task_official_url.sh "任务标题" "时间" "执行人" "清单"
```

### 方法 2：手动创建
1. 打开 **TickTick** 应用
2. 按 `Command+N` 或点击 "+" 按钮
3. 输入任务内容（例如：`上英语课 明天 09:00 @提子`）
4. 按 Enter 键保存

### 方法 3：邮件发送
通过发送邮件到 TickTick 的专用邮箱创建任务：
- **收件人**：`todo+elkk36yuo2eq@mail.ticktick.com`
- **主题**：任务标题
- **正文**：任务详情（包含时间、执行人等）

## 技术实现

### 官方 URL Scheme 格式
使用 TickTick 官方推荐的 URL Scheme 格式：

```
ticktick://x-callback-url/v1/add_task?title=任务标题&startDate=2026-02-23T09:00:00.000&allDay=false&content=任务内容&list=清单名称
```

### 支持的参数
- `title`：任务标题（必填）
- `startDate`：开始时间（ISO 8601 格式）
- `allDay`：是否全天任务
- `content`：任务内容
- `list`：任务所属列表
- `priority`：优先级（0=无，1=低，3=中，5=高）

## 日历识别逻辑

### 识别规则
1. **日期位置**：每一天的日期显示在日历格子的右上角
2. **课程标记**：老师名字显示在其对应日期格子的左侧
3. **格子边界**：每个格子是独立的，老师名字属于其所在的格子，而不是相邻格子
4. **完整检查**：检查所有格子，不遗漏任何有老师名字的日期

### 识别步骤
1. 打开日历截图
2. 遍历每个日历格子
3. 对每个格子：
   - 读取右上角的数字作为日期
   - 检查左侧是否有老师名字
   - 如果有老师名字，则记录该日期为有预约
4. 整理所有有预约的日期，形成完整列表
5. 提交给用户确认
6. 根据用户确认的日期创建待办事项

### 示例
对于 2025 年 12 月的日历截图，识别结果为：
- 12月1日、12月5日、12月8日、12月12日、12月15日、12月19日、12月22日、12月26日

## 从日历截图创建任务流程

1. **识别预约日期**：根据日历识别逻辑从截图中提取有预约的日期和时间
2. **生成确认表格**：将识别到的日期和时间整理成表格，包含以下信息：
   - 日期
   - 时间（识别到的原始时间）
   - 任务开始时间（提前10分钟）
   - 清单
3. **用户确认**：将表格提交给用户确认，等待用户确认无误
4. **创建任务**：用户确认后，创建一系列 bash 命令调用脚本创建任务：
   ```bash
   # 为每个日期创建任务
bash .trae/skills/ticktick-todo/create_task_official_url.sh "英语课" "2026-03-02 20:00" "" "🧚提子"
bash .trae/skills/ticktick-todo/create_task_official_url.sh "英语课" "2026-03-06 20:00" "" "🧚提子"
   ```
5. **验证任务**：检查滴答清单中是否成功创建了任务

## 时间处理逻辑

### 时间调整规则
- **任务开始时间**：识别到的时间 - 10分钟
- **任务内容时间**：显示识别到的原始时间
- **清单**：默认放入"🧚提子"清单
- **任务标题**：默认使用"英语课"

### 支持的时间格式
1. **相对时间**：
   - `今天 09:00`：今天上午9点
   - `明天 14:30`：明天下午2:30

2. **具体日期**：
   - `2026-03-02 20:00`：2026年3月2日晚上8点
   - `2026-03-06`：2026年3月6日全天

## 注意事项
- 此技能依赖于电脑已安装滴答清单软件
- 官方 URL Scheme 方法是最可靠的自动化方式，无需任何系统权限
- 邮件方法需要配置邮件发送功能
- 手动创建是最直接的方式，适用于所有场景
- 从日历截图创建任务时，必须先将识别结果整理成表格提交给用户确认，用户确认无误后再创建任务
- 任务开始时间会自动提前10分钟，任务内容显示原始时间
