# 滴答清单待办事项创建器

## 功能
- 打开电脑上的滴答清单软件
- 在滴答清单中创建新的待办事项
- 支持设置任务标题、描述、截止时间等属性
- 支持从日历截图中识别预约的日期和时间
- 自动将任务开始时间提前10分钟，任务内容显示原始时间

## 使用方法

### 方法 1：官方 URL Scheme（推荐）
使用 TickTick 官方推荐的 URL Scheme 方法，无需权限，直接创建任务：

```bash
# 运行此脚本创建任务
bash .trae/skills/ticktick-todo/create_task_official_url.sh "任务标题" "时间" "执行人" "清单"
```

### 方法 2：手动创建
1. 打开 **TickTick** 应用
2. 按 `Command+N` 或点击 "+" 按钮
3. 输入任务内容（例如：`上英语课 明天 09:00 @提子`）
4. 按 Enter 键保存

### 方法 3：邮件发送
通过发送邮件到 TickTick 的专用邮箱创建任务：
- **收件人**：`todo+elkk36yuo2eq@mail.ticktick.com`
- **主题**：任务标题
- **正文**：任务详情（包含时间、执行人等）

## 技术实现

### 官方 URL Scheme 格式
使用 TickTick 官方推荐的 URL Scheme 格式：

```
ticktick://x-callback-url/v1/add_task?title=任务标题&startDate=2026-02-23T09:00:00.000&allDay=false&content=任务内容&list=清单名称
```

### 支持的参数
- `title`：任务标题（必填）
- `startDate`：开始时间（ISO 8601 格式）
- `allDay`：是否全天任务
- `content`：任务内容
- `list`：任务所属列表
- `priority`：优先级（0=无，1=低，3=中，5=高）

## 日历识别逻辑

### 识别规则
1. **日期位置**：每一天的日期数字显示在日历格子的**右上角**
2. **课程标记**：老师名字显示在其对应日期格子的**左侧**
3. **格子边界**：每个格子是独立的，老师名字属于其所在的格子，而不是相邻格子
4. **完整检查**：检查所有格子，不遗漏任何有老师名字的日期

### ⚠️ 重要警告：日期识别常见错误
**错误案例**：曾发生将4号识别成3号、8号识别成7号的错误（所有日期都提前了一天）
**错误原因**：
- 日历格子的日期数字在右上角，老师名字在左侧
- 容易将**左边相邻格子**的日期误认为当前格子的日期
- 例如：Michele在4号的格子左侧，但误读了3号格子的日期

**正确识别方法**：
1. 先找到有老师名字（如Michele）的格子
2. **在这个格子内部**找右上角的日期数字
3. 确认老师名字和日期数字在**同一个格子内**
4. 不要看相邻格子的日期

### 识别步骤
1. 打开日历截图
2. 遍历每个日历格子
3. 对每个格子：
   - **先检查左侧是否有老师名字**
   - 如果有老师名字，则读取**该格子右上角**的数字作为日期
   - **关键验证**：确认老师名字和日期数字在同一个格子内，不是相邻格子
4. 整理所有有预约的日期，形成完整列表
5. **必须提交给用户确认**
6. **等待用户确认无误后**，才能创建待办事项

### 示例
对于 2025 年 12 月的日历截图，识别结果为：
- 12月1日、12月5日、12月8日、12月12日、12月15日、12月19日、12月22日、12月26日

### 日历识别示例（2026年5月）
正确的识别结果应该是：
- 4号（星期一）、8号（星期五）、11号（星期一）、15号（星期五）、18号（星期一）、22号（星期五）、25号（星期一）、29号（星期五）

错误的识别结果（所有日期提前一天）：
- 3号、7号、10号、14号、17号、21号、24号、28号 ❌

## 从日历截图创建任务流程

### ⚠️ 强制确认流程（必须严格遵守）
1. **识别预约日期**：根据日历识别逻辑从截图中提取有预约的日期和时间
2. **生成确认表格**：将识别到的日期和时间整理成表格，包含以下信息：
   - 日期
   - 时间（识别到的原始时间）
   - 任务开始时间（提前10分钟）
   - 清单
3. **提交确认**：将表格提交给用户，明确说明"请确认以上识别的日期是否正确"
4. **等待确认**：**必须等待用户明确回复确认后**，才能继续下一步
   - ❌ 错误：识别后直接创建任务
   - ✅ 正确：识别后等待用户确认，用户说"确认"或"正确"后才创建任务
5. **创建任务**：用户确认后，创建一系列 bash 命令调用脚本创建任务：
   ```bash
   # 为每个日期创建任务
   bash .trae/skills/ticktick-todo/create_task_official_url.sh "英语课" "2026-05-04 20:00" "" "🧚提子"
   bash .trae/skills/ticktick-todo/create_task_official_url.sh "英语课" "2026-05-08 20:00" "" "🧚提子"
   ```
6. **验证任务**：检查滴答清单中是否成功创建了任务

### 流程示例
```
步骤1：识别到以下日期
| 日期 | 时间 | 任务开始时间 | 清单 |
|------|------|--------------|------|
| 2026-05-04 | 20:00 | 19:50 | 🧚提子 |
| 2026-05-08 | 20:00 | 19:50 | 🧚提子 |

步骤2：提交给用户确认
"请确认以上识别的日期是否正确？"

步骤3：等待用户回复
- 如果用户说"正确"或"确认" → 继续创建任务
- 如果用户指出错误 → 重新识别

步骤4：用户确认后创建任务
```

## 时间处理逻辑

### 时间调整规则
- **任务开始时间**：识别到的时间 - 10分钟
- **任务内容时间**：显示识别到的原始时间
- **清单**：默认放入"🧚提子"清单
- **任务标题**：默认使用"英语课"

### 支持的时间格式
1. **相对时间**：
   - `今天 09:00`：今天上午9点
   - `明天 14:30`：明天下午2:30

2. **具体日期**：
   - `2026-03-02 20:00`：2026年3月2日晚上8点
   - `2026-03-06`：2026年3月6日全天

- 此技能依赖于电脑已安装滴答清单软件
