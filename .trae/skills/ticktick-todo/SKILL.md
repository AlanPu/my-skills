# 滴答清单待办事项创建器

## 功能
- 打开电脑上的滴答清单软件
- 在滴答清单中创建新的待办事项
- 支持设置任务标题、描述、截止时间等属性

## 使用方法
1. 确保电脑已安装滴答清单软件
2. 调用此技能时，提供待办事项的详细信息
3. 技能会自动打开滴答清单并创建任务

## 示例
- "帮我用滴答清单创建一个待办事项，标题是 '完成项目报告'"
- "打开滴答清单，添加任务 '购买生日礼物'，设置明天截止"

## 注意事项
- 此技能依赖于电脑已安装滴答清单软件
- 在 macOS 系统上，使用 `open -a 滴答清单` 命令打开软件
- 在 Windows 系统上，需要使用对应路径打开软件
- 目前仅支持基本的任务创建功能
